# MANGO WORLD QA v1.8 — 22 November 2026

## Work performed
- Continued from the recovered QA v1.6 project structure.
- Changed the ERC-20 constructor to require an explicit nonzero initial-holder address. This avoids silently treating the deployer as the approved token recipient.
- Added tests for metadata, exact supply, transfers, zero initial-holder rejection, and absence of owner/mint methods.
- Added a Sepolia-only deployment script. It refuses other networks and requires `INITIAL_HOLDER`.
- Added `.env.example` and ignored `.env`.
- Added the Hardhat Chai matchers plugin required by revert and balance-change assertions; aligned the Sepolia network configuration with Hardhat 2.x.
- Added a static QA suite for the new contract and deployment safeguards.
- Added a Supabase/Postgres schema draft with row-level security for profiles, wallet links, listings, orders, ledger and admin audit log.
- Expanded the React frontend with navigation for token, marketplace, admin and roadmap status; unimplemented areas are explicitly marked inactive.
