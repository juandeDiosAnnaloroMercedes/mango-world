# Mainnet launch gate

- [ ] Confirm token name, symbol, 100,000,000 cap and 18 decimals.
- [ ] Approve allocation table; no allocation is currently set.
- [ ] Confirm deployer and treasury wallet ownership and security.
- [ ] Legal review: MiCA, Italian implementation, marketing, public offer, exchange, custody and transfer services.
- [ ] Security review / independent audit of exact final bytecode.
- [ ] Reproducible build and verified source.
- [ ] Test deployment on Sepolia; verify fixed supply and transfer behavior.
- [ ] User-facing risk disclosures and privacy policy.
- [ ] Incident response and support process.
- [ ] Explicit written approval before mainnet deployment or handling real funds.
